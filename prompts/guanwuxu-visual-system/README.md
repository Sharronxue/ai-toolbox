# 观物序 · 东方茶器广告视觉规范

> 一套可反复使用的高端茶器广告视觉系统：固定品牌审美，变化每件产品的创意。

## 这是什么

这不是一条普通提示词，而是一套**品牌视觉规范**。写好一次，以后换任何一只杯子、一把壶、一套茶席——甚至换成漆器、香器——都不需要从头解释审美。只需提供新产品实拍图 + 填一张「单品创意卡」，AI 就能在保持品牌视觉气质的基础上，为每件产品重新构思画面、文化主题和广告叙事。

## 核心理念

> 固定的是审美标准，不固定的是版式；固定的是品牌气质，不固定的是创意表达。

所有作品属于同一个高端品牌，但每个产品都有自己的广告创意——不是不断换产品的模板。

## 文件结构

## 使用流程

```
第一次：通读「设计方法论」，理解为什么这样定规则
         ↓
每次创作：
  1. 拍好产品实拍图（正面/侧面/俯拍/底款/包装）
  2. 填写「单品创意卡」
  3. 复制「母提示词」全文 + 单品创意卡 + 实拍图 → 一起发给 AI
  4. （推荐）先让 AI 出 3 个创意方向 → 选定 → 再正式出长图
```

## 一句话触发

> 按「观物序高端茶器暗调广告规范」设计这款产品。保持参考图的暗调质感、文化张力和灵活排版，但请为这件产品重新寻找视觉主题，优先突出器物本身与它独特的文化价值。

再附上新产品的真实图片和资料即可。
