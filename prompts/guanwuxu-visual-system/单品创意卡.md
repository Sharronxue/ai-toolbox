# 单品创意卡

> 每次制作新产品时填写本卡，与「母提示词」及产品实拍图一起发给 AI。
> 最有价值的不是把产品资料写得越来越长，而是告诉 AI：产品是什么、最独特的地方在哪里、希望传达什么。

---

| 字段 | 填写示例 |
|------|---------|
| 产品名称 / 品类 | 莲花形品茗杯 / 陶瓷茶器 |
| 真实釉色 / 材质 | 粉青釉 / 原矿瓷土 |
| 核心特征（最多三项更有效） | 器型优美、釉色温润、传统出筋工艺 |
| 想传达的文化意境 | 东方清雅、文人品茗、传统工艺 |
| 目标客户 / 使用场景 | 品茗爱好者 / 日常茶席、礼赠 |
| 绝对不能改动的细节 | 真实器型、釉色、底款、包装标识 |
| 额外资料（可选） | 工艺传承、获奖记录、产地等 |

---

## 使用说明

1. 拍好产品实拍图——对陶瓷尤其重要：**正面、侧面、俯拍、底款和包装图**。图片比文字描述更能帮助 AI 理解产品真实结构。
2. 填写上表（可删掉示例行，只留你的内容）。
3. 复制「母提示词」全文 + 本卡 + 实拍图，一起发给 AI。
4. （推荐）先让 AI 出 3 个创意方向，选定后再正式出长图。

> 填卡原则：核心特征最多写三项，多了反而模糊；文化意境写一个方向，不要什么都想要。
