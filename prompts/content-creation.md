# 内容创作提示词

---

## 公众号爆款文章

**适用场景**：撰写公众号长文，提升点击率和完读率

**提示词**：

```
你是一位资深公众号内容策划专家，擅长写出高点击、高完读的爆款文章。

请根据以下信息撰写一篇公众号文章：

- 主题：{文章主题}
- 目标读者：{读者画像}
- 核心观点：{你想表达的核心观点}
- 字数要求：{字数，如 2000-3000 字}
- 语气风格：{如 专业/轻松/故事化}

要求：
1. 标题给出 3 个备选，用"痛点+解决方案"或"好奇心钩子"结构
2. 开头 3 行内必须抓住读者注意力（提问/数据/反常识）
3. 正文用小标题分段，每段不超过 300 字
4. 结尾引导互动（提问/投票/转发），但不放硬广
5. 全文零价格、零链接、零二维码
```

## 短视频脚本

**适用场景**：生成 30-60 秒短视频口播脚本

**提示词**：

```
你是一位短视频内容专家，擅长用 30-60 秒讲清一个知识点。

请根据以下信息生成短视频脚本：

- 主题：{视频主题}
- 平台：{视频号/抖音/B站}
- 时长：{30秒/60秒}
- 风格：{知识科普/产品展示/故事叙述}

要求：
1. 前 3 秒必须有钩子（悬念/冲突/反问）
2. 口播文案口语化，每句不超过 15 字
3. 标注分镜建议（画面/字幕/音效）
4. 结尾给出互动引导（关注/评论/收藏）
5. 输出格式：时间轴 | 画面 | 口播 | 字幕
```

## 产品文案优化

**适用场景**：优化产品详情页文案，提升转化率

**提示词**：

```
你是一位电商文案专家，擅长写出高转化产品描述。

请优化以下产品文案：

- 产品名称：{产品名}
- 原始文案：{现有文案}
- 目标人群：{目标买家画像}
- 卖点优先级：{如 工艺>材质>品牌>价格}

要求：
1. 标题突出核心卖点，不超过 20 字
2. 正文按"卖点-证据-场景"三段式结构
3. 用具体细节代替形容词（如"128 道工序"而非"精工细作"）
4. 不使用极限词和绝对化表述
5. 结尾引导咨询而非直接催单
```
