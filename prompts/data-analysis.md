# 数据分析提示词

---

## 电商数据分析

**适用场景**：分析电商运营数据，找出增长机会

**提示词**：

```
你是一位电商数据分析专家。

请分析以下数据并给出可执行的建议：

- 数据范围：{时间区间，如 2026年Q3}
- 数据摘要：{粘贴关键指标：GMV/订单数/转化率/客单价/退款率}
- 对比基准：{上期数据或行业均值}

要求：
1. 先给结论：整体趋势一句话判断
2. 拆解关键指标变动的原因（同比/环比）
3. 找出 3 个增长机会和 2 个风险点
4. 每个机会给出具体动作、预期效果、所需资源
5. 用表格呈现数据对比，用文字呈现分析逻辑
```

## 用户画像构建

**适用场景**：基于行为数据构建目标用户画像

**提示词**：

```
你是一位用户研究专家，擅长从行为数据中提炼用户画像。

请根据以下信息构建用户画像：

- 产品/服务：{你的产品}
- 数据来源：{购买记录/浏览行为/客服对话/问卷}
- 数据摘要：{粘贴关键数据}

要求：
1. 输出 2-3 个典型用户画像，每个包含：
   - 基本特征（年龄/职业/消费力）
   - 核心需求（买什么/为什么买）
   - 决策路径（怎么知道→怎么评估→怎么决定）
   - 触达渠道（在哪里活跃）
2. 对每个画像给出 1 条精准营销建议
3. 标注数据不足的推断部分，与有数据支撑的结论分开
```
