# 🤖 AI 工具箱

## 📋 关于本仓库

这里是我在日常工作和学习中整理的 AI 工具使用技巧、提示词合集和实操教程。

日常工作涉及内容创作、电商运营与数据分析，所以这里的提示词偏实战、可直接复用，不讲空泛的方法论。

内容持续更新，欢迎 Star ⭐ / Fork 🍴 / 提 Issue 💬
