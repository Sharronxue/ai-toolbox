## ⭐ 旗舰内容

### [观物序 · 东方茶器广告视觉规范](./prompts/guanwuxu-visual-system/)

一套可反复使用的高端茶器广告视觉系统：**固定品牌审美，变化每件产品的创意**。

写好一次，以后换任何一只杯子、一把壶、一套茶席——甚至换成漆器、香器——都不需要从头解释审美。只需提供新产品实拍图 + 填一张「单品创意卡」。

| 文件 | 用途 |
|------|------|
| [母提示词](./prompts/guanwuxu-visual-system/母提示词.md) | V1.0 完整规范，复制即用 |
| [单品创意卡](./prompts/guanwuxu-visual-system/单品创意卡.md) | 每次换产品填这张表 |
| [设计方法论](./prompts/guanwuxu-visual-system/设计方法论.md) | 六条设计规则 + 广告叙事骨架 |

> 暗调东方美学 × 器物质感 × 中国文化叙事。让人第一眼被吸引，第二眼看见工艺，第三眼读懂文化。
